# Dikzzy.eth — Portfolio

Personal portfolio web for [Dikzzy.eth](https://github.com/diki-wah), built as a static site with no framework and no build step.

## Includes
- Dark Web3-themed portfolio sections (about, focus, projects, contact)
- **Dragon Run** — a small dependency-free canvas mini-game (dodge shards, collect coins)
- Responsive layout and lightweight interactions

## Run locally
Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

## Stack
- HTML / CSS / vanilla JavaScript
- Canvas 2D for the game
